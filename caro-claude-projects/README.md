# Proyectos de Claude.ai para CVS Latino Services LLC

Esta carpeta tiene 4 proyectos listos para crear en Claude.ai. Cada proyecto ayuda a Carolina Beelitz, Notaria Pública en Freehold, New Jersey, con una parte de su trabajo.

Los 4 proyectos:

1. Formularios USCIS: organizar la información del cliente y prepararla pregunta por pregunta, en inglés, para que Carolina la escriba en el formulario oficial.
2. Traducciones certificadas: traducir documentos civiles del español al inglés de forma completa y literal, con certificado de traductor.
3. Documentos notariales: llenar plantillas que el cliente completa con sus propios datos.
4. Negocio y marketing: mensajes a clientes, facturas, acuerdos de servicio y textos para flyers y redes.

## Cómo crear cada proyecto en Claude.ai

Para cada carpeta (01, 02, 03, 04):

1. En Claude.ai, crea un proyecto nuevo. Usa el nombre de la carpeta como nombre del proyecto.
2. Abre el archivo `instrucciones-del-proyecto.md` de esa carpeta. Copia todo su contenido y pégalo en la sección de instrucciones del proyecto (Project instructions).
3. Sube los demás archivos `.md` de esa carpeta como conocimiento del proyecto (Project knowledge).
4. Repite con las 4 carpetas.

## Reglas de privacidad para Carolina

1. No subas documentos de clientes al conocimiento del proyecto. El conocimiento es para plantillas y guías, no para datos de personas.
2. Trabaja caso por caso en el chat, con los datos mínimos necesarios.
3. Cuando termines un caso, borra el chat que tenga datos sensibles del cliente.
4. Usa solo las iniciales del cliente en títulos y notas, no el nombre completo.

## Recordatorio importante

Todo lo que produce Claude es un borrador. Carolina lo revisa siempre antes de usarlo con un cliente o con una agencia oficial. Claude no da asesoría legal.
