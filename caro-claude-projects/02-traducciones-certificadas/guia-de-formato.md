# Guía de formato para traducciones

Estructura recomendada para una traducción certificada.

## 1. Encabezado

En la parte de arriba, una línea que identifique el documento:

> Translation from Spanish to English
> Document type: [por ejemplo, Birth Certificate]

## 2. Cuerpo de la traducción

- Sigue el mismo orden del documento original, de arriba abajo.
- Reproduce la estructura: títulos, secciones, campos, tablas.
- Para cada campo, pon la etiqueta y el valor como en el original.
- Elementos no textuales entre corchetes, en el idioma de destino:
  - [Seal: ...]
  - [Signature] o [Illegible signature]
  - [Official stamp: ...]
  - [Coat of arms]
  - [Barcode]
- Texto que no se lee: [illegible].

## 3. Notas del traductor

Cuando algo necesite aclaración, usa una nota breve entre corchetes dentro del texto:

> [Translator's note: the original shows an apparent spelling error in the surname]

No cambies el contenido original. La nota solo explica, no corrige.

## 4. Certificado de traductor

Al final del documento va el certificado de traducción. Usa la plantilla del archivo certificado-de-traduccion.md.

## 5. Revisar contra el original

Después del certificado, agrega una lista en español para Carolina con todo lo que necesita cotejar contra el documento original:

- Cada carácter marcado con [?]
- Cada parte marcada como [illegible]
- Cualquier dato marcado como REVISAR

Carolina confirma estos puntos contra el original antes de firmar la certificación.

## Recordatorio

La traducción debe ser completa y exacta. Nada se resume ni se omite. Carolina revisa el borrador antes de certificar.
